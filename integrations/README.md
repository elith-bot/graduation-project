# Integrations

التقنية المعتمدة: Python + إعدادات Wazuh.

المسؤوليات: إعداد مختبر المراقبة، موصل Wazuh، تحويل الحقول إلى contracts، وتوثيق فشل الاتصال وآلية إعادة المحاولة ومنع إعادة إدخال الحدث نفسه.

تُرسل البيانات إلى backend ولا يكتب الموصل في قاعدة بياناته مباشرة. توثق طريقة الربط وإعدادها قبل التنفيذ. الأسرار محلية فقط، والعينات المنشورة اصطناعية.

يضيف التصميم الموحد قراءة معلومات المكونات والإعدادات ودلائل اختبار المسارات والفترة التي تخصها. نقص حدث لا يصنف فشلاً دون تحقق من النشاط والتوقيت والصلاحيات. تشغيل تجارب العطل مهمة مختبر مصرح بها، لا سلوكاً تلقائياً للموصل. المرجع [صمود الكشف](../docs/DETECTION_RESILIENCE.md).

المرجع: [الهيكلية](../docs/ARCHITECTURE.md)، [العقود](../contracts/README.md)، [طريقة العمل](../CONTRIBUTING.md).

ابدأ بـ[شرح Wazuh ومختبره](../docs/WAZUH.md). نتحقق من تغطية محاولات الدخول والنجاح والنشاط اللاحق قبل الادعاء بأن بيانات المصدر تكفي للقواعد الخمس. توثق طريقة القراءة والإصدار والاستئناف؛ ولا تفترض أن Server API وIndexer API يؤديان الدور نفسه.
