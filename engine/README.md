# Engine

التقنية المعتمدة: Python.

المسؤوليات: دمج المتكرر، ربط التنبيهات بحوادث، حساب أولوية مفسرة، وإنتاج أسباب القرار وخطوات التحقيق المقترحة وفق contracts.

يبدأ كوحدة يستدعيها backend. لا يتصل بقاعدة البيانات أو Wazuh مباشرة. يجب أن يمكن اختبار منطقه على عينات ثابتة دون تشغيل واجهة أو مختبر.
