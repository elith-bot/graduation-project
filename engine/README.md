# Engine

التقنية المعتمدة: Python.

المسؤوليات: دمج المتكرر، ربط التنبيهات بحوادث، حساب أولوية مفسرة، وإنتاج أسباب القرار وخطوات التحقيق المقترحة وفق contracts.

النطاق الموحد يضيف investigation/ لكفاية الأدلة وإعادة التقييم وresilience/ للتبعيات والتحقق ومحاكاة الفشل والتوصيات. هذه أقسام مستهدفة لا شفرة منفذة بعد. تقرأ [SYSTEM_FLOW](../docs/SYSTEM_FLOW.md) و[DETECTION_RESILIENCE](../docs/DETECTION_RESILIENCE.md) قبل التنفيذ؛ ML توسع لاحق.

يبدأ كوحدة يستدعيها backend. لا يتصل بقاعدة البيانات أو Wazuh مباشرة. يجب أن يمكن اختبار منطقه على عينات ثابتة دون تشغيل واجهة أو مختبر.

المرجع: [الهيكلية](../docs/ARCHITECTURE.md)، [العقود](../contracts/README.md)، [طريقة العمل](../CONTRIBUTING.md).

التصميم التفصيلي في [قواعد المحرك والهجين](../docs/ENGINE_RULES.md): خمس قواعد أولاً، ثم خصائص وتنبؤ ML في Shadow Mode وسياسة قرار مفسرة. لا يضم هذا المجلد حالياً كوداً منفذاً. تحويل حقول Wazuh يبقى داخل integrations؛ لا يكرر هنا normalizer خاص بالمصدر.
