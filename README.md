# Automated SOC Analyst Assistant & Incident Triage Engine

مشروع تخرج قسم هندسة الأمن السيبراني: مساعد محلل مركز العمليات الأمنية ومحرك الفرز الأولي للحوادث.

يستقبل التنبيهات الأمنية، ويجمع المتكرر منها، ويربط الأحداث بحوادث، ثم يرتب الأولويات ويعرض الأدلة وخطوات التحقيق المقترحة. Wazuh مصدر للتنبيهات؛ مساهمة الفريق هي محرك الربط والفرز والتفسير والتقييم. الاستجابة في النسخة الأولى توصيات يراجعها المحلل.

## المرجع المعتمد للفريق

الهيكلية في [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) هي المرجع المعتمد لحدود الأجزاء والتقنيات. أي تغيير عليها يمر بطلب دمج ومراجعة الأعضاء المتأثرين.

| المجلد | المسؤولية | التقنية |
|---|---|---|
| backend/ | استقبال البيانات والتخزين وواجهة API | Python + FastAPI |
| engine/ | ربط الأحداث ودمج المتكرر وترتيب الأولويات | Python |
| frontend/ | واجهة المحلل والحوادث والتقارير | React + TypeScript |
| integrations/ | ربط Wazuh وتحويل بياناته | Python + إعدادات Wazuh |
| evaluation/ | السيناريوهات وبيانات الاختبار وقياس النتائج | Python |
| contracts/ | عقود البيانات المشتركة | مواصفات موثقة، ثم مخططات قابلة للتحقق |
| docs/ | البحث والتوثيق والقرارات | Markdown |
