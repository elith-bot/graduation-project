# عقود البيانات المشتركة

هذا المجلد هو المرجع المشترك لشكل البيانات بين integrations وbackend وengine وfrontend وevaluation. لم تعتمد مخططات نهائية بعد؛ يتفق عليها الفريق قبل التنفيذ المتوازي.

صيغة تبادل بيانات الواجهة مع FastAPI هي JSON عبر /api/؛ تستخدم الواجهة fetch(). تُوثق عقود الطلب والاستجابة والأخطاء قبل تنفيذ العمليات. ملفات الواجهة والتقارير المنزلة ليست ملزمة بصيغة JSON.

## المطلوب اعتماده أولاً

- Alert: معرف التنبيه، مصدره ومعرف الحدث الأصلي، وقت الحدث مع المنطقة الزمنية، الجهاز، النوع، الشدة الأصلية، والأدلة.
- Incident: معرف الحادث، التنبيهات المرتبطة، التصنيف، بداية ونهاية الخط الزمني، الأولوية، أسبابها، الأدلة، حالة التحقيق، والخطوات المقترحة.
- تحديد الحقول المطلوبة والاختيارية وأنواعها، معنى القيم الفارغة، أسماء درجات الأولوية، قواعد المعرفات وإزالة التكرار، وأخطاء التحقق.
- تحديد نطاق مسؤولية شدة المصدر مقابل أولوية المحرك؛ لا يخلط بينهما.
- عينات اصطناعية صالحة وأخرى غير صالحة ومخططات قابلة للتحقق مثل JSON Schema، ثم مواصفات API عند تنفيذ backend.

تعتمد الأوقات ISO 8601 مع منطقة زمنية صريحة. لا تحتوي العينات على أسرار أو بيانات حوادث شخصية. يحدد مسار توليد العقود والتحقق منها عند التنفيذ لتجنب نسخ تعريفات متعارضة بين Python وJavaScript.

## إضافات مطلوبة لدعم التحليل السياقي والهجين

- فصل event_time عن received_at وdecision_time مع ISO 8601 والمنطقة الزمنية؛ ما يصل لاحقاً لا يستخدم لتقييم قرار سابق دون إصدار جديد.
- هوية مصدر ثابتة لإعادة الإرسال؛ تعريف deduplication_key لا يحذف أحداثاً متميزة متشابهة.
- المصدر والجهاز والحساب والجلسة إن توفرت، مع provenance لكل قيمة. حقول MFA ومعرفة المصدر/الجهاز ثلاثية القيمة أو تحمل حالة توفر صريحة؛ unknown ليس false ولا benign.
- الحادث يحمل معرفات الأدلة الأصلية، إصدار القواعد/الإعدادات، وقت القرار، درجة القواعد وأسبابها، الأولوية، وحالة المراجعة منفصلة عن judgment.
- نتائج ML الاختيارية تحمل model_version وfeature_version وmode=shadow/active وحالة التنبؤ. الفشل أو غياب النموذج ظاهر ولا يمنع نتائج القواعد.
- تعريف مفاتيح الربط والنوافذ الزمنية ومعالجة الأحداث المتأخرة، وعينات حدود زمنية وحقول مفقودة، قبل تنفيذ المخططات.
- توثيق حقول feedback: حكم المحلل وصاحبه ووقته وملاحظته، دون اعتبار الوسوم صالحة للتدريب تلقائياً.

هذه متطلبات للعقد القادم وليست مخطط JSON معتمداً بعد؛ أمثلة أسماء الحقول هنا إرشادية. المرجع السلوكي [قواعد المحرك](../docs/ENGINE_RULES.md).

## متطلبات عقود المنصة الموحدة

عقود JSON التالية هدف تصميم؛ أول مهمة T01 تحول الحد الأدنى منها إلى مخططات وأمثلة قابلة للتحقق. لا تدعي هذه القائمة وجود API منفذ أو schema نهائية.

| الكيان | الحقول المطلوبة منطقياً |
|---|---|
| EvidenceAssessment | incident_id، requirement_id، حالة الدليل، المصدر، السبب، الأوقات، evidence_ids |
| CoverageAssessment | asset_id، scenario_id، الحالة، valid_from/valid_until، وقت التقييم، config_version، test_run_ids، نطاق القيود |
| DetectionComponent | component_id، type، asset/scope، حالته المرصودة ووقت رصدها ومصدرها |
| DetectionPath | path_id، scenario_id، المكونات المطلوبة، نقطة النجاح، شروط الحقول، دليل الاختبار وإصدار الخريطة |
| TestRun | test_id، النشاط المتوقع، المدخل، الفشل المفروض، نقطة الرصد، الفعلي، timeout، الإعداد، evidence_ids، موافقة/استعادة |
| FailureSimulation | graph_version، failure_components، حد k، حدود النموذج، المسارات المتأثرة والناجية وunknown، simulated=true |
| Recommendation | نوع repair/resilience، المشكلة، المكونات، التغيير المقترح، نطاق الحماية، الكلفة ومصدرها، شروط التحقق |
| Verification | before/after test_ids، تطابق السيناريو والعطل، النتيجة والقيود، التحسن المقاس أو unverified |

أول مجموعة تنفيذية: Alert وIncident وEvidenceAssessment وCoverageAssessment مع عينة؛ بقية المخططات قبل تنفيذ وحدة الصمود. كل مخرج يحمل schema_version ومعرفات ثابتة قابلة للتتبع. الحالات المصطلحية مصدرها [التسلسل](../docs/SYSTEM_FLOW.md)؛ لا نساوي checklist الدليل مع حالة coverage أو priority أو judgment.

نتيجة تغطية اليوم لا تؤكد فترة أمس؛ لا يقبل مرجع test_id دون ضبط الجهاز والسيناريو والإصدار والفترة. لا نعلن missing_telemetry إذا غاب الحقل فقط؛ نميز التأخر والصلاحيات وعدم التهيئة وعدم المعرفة.

## مراجعة التغيير المشترك

أي تغيير يراجع من أصحاب الأجزاء المنتجة والمستهلكة. التغيير غير المتوافق يوضح أثره وخطة تحديث المكونات، وتحدث العينات والمخططات والتوثيق ضمن طلب الدمج نفسه.
