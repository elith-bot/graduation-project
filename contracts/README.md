# عقود البيانات المشتركة

هذا المجلد هو المرجع المشترك لشكل البيانات بين integrations وbackend وengine وfrontend وevaluation. لم تعتمد مخططات نهائية بعد؛ يتفق عليها الفريق قبل التنفيذ المتوازي.

## المطلوب اعتماده أولاً

- Alert: معرف التنبيه، مصدره ومعرف الحدث الأصلي، وقت الحدث مع المنطقة الزمنية، الجهاز، النوع، الشدة الأصلية، والأدلة.
- Incident: معرف الحادث، التنبيهات المرتبطة، التصنيف، بداية ونهاية الخط الزمني، الأولوية، أسبابها، الأدلة، حالة التحقيق، والخطوات المقترحة.
- تحديد الحقول المطلوبة والاختيارية وأنواعها، معنى القيم الفارغة، أسماء درجات الأولوية، قواعد المعرفات وإزالة التكرار، وأخطاء التحقق.
- تحديد نطاق مسؤولية شدة المصدر مقابل أولوية المحرك؛ لا يخلط بينهما.
- عينات اصطناعية صالحة وأخرى غير صالحة ومخططات قابلة للتحقق مثل JSON Schema، ثم مواصفات API عند تنفيذ backend.

تعتمد الأوقات ISO 8601 مع منطقة زمنية صريحة. لا تحتوي العينات على أسرار أو بيانات حوادث شخصية. يحدد مسار توليد العقود والتحقق منها عند التنفيذ لتجنب نسخ تعريفات متعارضة بين Python وTypeScript.

## التغيير

أي تغيير يراجع من أصحاب الأجزاء المنتجة والمستهلكة. التغيير غير المتوافق يوضح أثره وخطة تحديث المكونات، وتحدث العينات والمخططات والتوثيق ضمن طلب الدمج نفسه.
