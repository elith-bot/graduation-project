# Backend

التقنية المعتمدة: Python + FastAPI.

المسؤوليات: استقبال التنبيهات والتحقق من contracts، التخزين وترحيلات قاعدة البيانات، استدعاء engine، وتوفير API للواجهة والتقارير.

لا يعيد هذا الجزء تنفيذ قواعد الربط والأولوية. اختيار قاعدة البيانات وأوامر التشغيل وإصدارات الاعتماديات ينتظر مرحلة تجهيز التنفيذ.

المرجع: [الهيكلية](../docs/ARCHITECTURE.md)، [العقود](../contracts/README.md)، [طريقة العمل](../CONTRIBUTING.md).
