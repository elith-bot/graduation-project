# Backend

التقنية المعتمدة: Python + FastAPI.

يقدم API لتبادل البيانات بصيغة JSON تحت /api/، ويقدم ملفات HTML/CSS/JavaScript من frontend من نفس الأصل في النسخة الأولى. توثق نماذج الطلبات والاستجابات والأخطاء بالتنسيق مع contracts. تنزيل ملفات التقارير له استجابة ملف مناسبة.

المسؤوليات: استقبال التنبيهات والتحقق من contracts، التخزين وترحيلات قاعدة البيانات، استدعاء engine، وتوفير API للواجهة والتقارير.

لا يعيد هذا الجزء تنفيذ قواعد الربط والأولوية أو تحليل الفشل. SQLite اختيار النسخة المحلية وفق [ADR](../docs/adr/0001-unified-platform.md)؛ الترحيلات وأوامر التشغيل والإصدارات تثبت عند التنفيذ. يحفظ أدلة الاختبار ونسخ القرار والخريطة وسجل التدقيق ويقدمها للمحرك.

المرجع: [الهيكلية](../docs/ARCHITECTURE.md)، [العقود](../contracts/README.md)، [طريقة العمل](../CONTRIBUTING.md).
