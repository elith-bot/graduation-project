# Frontend

التقنية المعتمدة: HTML + CSS + JavaScript دون React أو TypeScript أو خطوة بناء.

المسؤوليات: قائمة التنبيهات والحوادث والبحث والتصفية، تفاصيل الحادث، الأولوية والأدلة والخط الزمني وعرض التقارير.

للنطاق الموحد تعرض checklist الأدلة وحالة coverage مستقلة، وخريطة صغيرة ومسارات مختبرة، ومحاكاة فشل حسابية وتقرير مقارنة قبل/بعد. لا تعطل أجهزة أو تطبق تحسيناً بمجرد ضغط زر؛ يظهر فرق simulated وverified وunknown. الواجهة المقترحة تبقى HTML/CSS/JavaScript، وليست Streamlit الواردة بالمصدر التاريخي.

يستهلك JSON من مسارات /api/ باستخدام fetch()، ويبدأ بعينات contracts عند انتظار التكامل. لا يحسب الأولوية بنفسه ولا يتصل بـWazuh مباشرة. يقدم FastAPI ملفات الواجهة من نفس الأصل؛ لا تفتح الصفحات عبر file:// للتكامل.

التنظيم المستهدف عند التنفيذ: index.html، وcss/styles.css، وjs/api.js للاتصال، وjs/alerts.js وjs/incidents.js للعرض، وassets/ للموارد. هذه أسماء تنظيمية مقترحة وليست ملفات تطبيق منفذة بعد.

المرجع: [الهيكلية](../docs/ARCHITECTURE.md)، [العقود](../contracts/README.md)، [طريقة العمل](../CONTRIBUTING.md).
