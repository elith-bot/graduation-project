# Evaluation

التقنية المعتمدة: Python.

المسؤوليات: سيناريوهات مختبرية وبيانات اصطناعية موسومة، النتائج المتوقعة، اختبار المسار المتكامل، وقياس التجميع والأولوية وتقليل التنبيهات وزمن المعالجة مقابل خط أساس موثق.

بعد الدمج يشمل الاختبار مقارنة فرز واعٍ بالتغطية بفرز فقط، وصحة توقع أثر الأعطال، وحساب مجموعات الفشل على حالات صغيرة، وتحسيناً واحداً قبل/بعد بنفس السيناريو. يحتفظ بسجل موافقة المختبر والاستعادة ويميز المحاكاة عن التجربة؛ لا يدعي تحسناً فعلياً إذا لم يتوفر مختبر.

تبدأ السيناريوهات بفشل دخول متكرر ثم نجاح، إنشاء مستخدم ثم رفع صلاحياته، وتعديل ملف حساس. تحفظ توقعات النتائج قبل ضبط قواعد المحرك، وتفصل بيانات الضبط عن التقييم.

يوثق كل جزء اختباراته الخاصة بجوار كوده؛ هذا المجلد يملك اختبارات السيناريوهات والتقييم المشترك. لا يحتوي على برمجيات ضارة أو بيانات حوادث حقيقية.

المرجع: [الهيكلية](../docs/ARCHITECTURE.md)، [العقود](../contracts/README.md)، [طريقة العمل](../CONTRIBUTING.md).

المرجع التفصيلي [خطة التقييم](../docs/EVALUATION_PLAN.md): سيناريوهات موسومة مستقلة، فصل التدريب والتطوير والاختبار، مقارنة القواعد وHybrid وخط الأساس، وقياس Recall وPrecision وأخطاء التخفيض وتقليل قائمة العمل. لا توجد نتائج مقاسة حالياً. تدريب وتنبؤ النموذج يتبع engine/؛ إعداد التقييم المستقل وتقاريره هنا.
