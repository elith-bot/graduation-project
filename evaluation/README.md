# Evaluation

التقنية المعتمدة: Python.

المسؤوليات: سيناريوهات مختبرية وبيانات اصطناعية موسومة، النتائج المتوقعة، اختبار المسار المتكامل، وقياس التجميع والأولوية وتقليل التنبيهات وزمن المعالجة مقابل خط أساس موثق.

تبدأ السيناريوهات بفشل دخول متكرر ثم نجاح، إنشاء مستخدم ثم رفع صلاحياته، وتعديل ملف حساس. تحفظ توقعات النتائج قبل ضبط قواعد المحرك، وتفصل بيانات الضبط عن التقييم.

يوثق كل جزء اختباراته الخاصة بجوار كوده؛ هذا المجلد يملك اختبارات السيناريوهات والتقييم المشترك. لا يحتوي على برمجيات ضارة أو بيانات حوادث حقيقية.
