# سجل الأفكار والمساهمة البحثية

## القرار الحالي

الدمج المتسلسل: فرز أولي → فحص الأدلة والتغطية → إعادة قرار التحقيق → تحليل تبعيات ومحاكاة فشل → تحسين واختبار. اسم المنصة وصفي، وSHIELD-X اسم وحدة الصمود. لا نبدل تقنيات الفريق بStreamlit أو React لمجرد ورودها بالمحادثات.

| الفكرة | موقعها الحالي | السبب |
|---|---|---|
| SOC triage وتجميع وربط | أساس MVP | يقلل قائمة العمل ويقدم نقطة دخول للتحقيق |
| كفاية الأدلة والحقول المفقودة | أساس MVP بصورة checklist | يمنع اعتبار نقص المعلومات سلامة |
| التغطية والتبعيات ومجموعات الفشل | أساس محدود بسيناريو كشف | يفسر حدود الأدلة ويختبر صمود الكشف |
| تحسين واحد واختبار قبل وبعد | شرط الادعاء بتحسن حقيقي | يميز التوصية عن نتيجة مثبتة |

## السؤالان الرئيسيان

1. هل إدخال حالة تغطية مختبرة ومحددة بالوقت يقلل الإغلاق الخاطئ أو التخفيض الخاطئ للحوادث عند فقد الأدلة مقارنة بالفرز وحده؟
2. هل خريطة التبعيات المدعومة باختبارات تتوقع أثر فشل المكونات ضمن النطاق، وهل تحسين مختبر يرفع تحمل ذلك الفشل مقارنة بطرق أبسط؟

نقيس أثر كل جزء منفصلاً ثم المسار الموحد. قد لا يتحسن الأداء؛ النتيجة السلبية الموثقة جزء من البحث وليست سبباً لتغيير الوسوم.

## ما لا ندعيه

Wazuh لديه جمع وقواعد وربط واختبار وحالة Agents. التجميع أو رسم Graph أو حساب cut/hitting sets أو استعمال RandomForest ليست اختراعات جديدة بمفردها. تسمية MDFS ليست إثبات سبق. الأصالة المحتملة في طريقة الدمج والنمذجة والتحقق والتقييم المحدد، وتحتاج مراجعة أعمال سابقة وتجارب.

المحادثات ذكرت Wazuh Mobius وWARDEN وTRUST-SOC وWraith وبحث Sensor Placement وأدوات تدقيق كشف. هذه أسماء مرشحة للبحث، لا مراجع تحققنا منها أو برهان أنها موجودة بالصفات المنقولة. لا تضاف للببليوغرافيا قبل التحقق من المصدر الأصلي والعنوان والمؤلف والتاريخ والوظيفة.

## مهمة مراجعة الأدبيات

لكل أقرب عمل: رابط أولي موثوق، وصف موثق، المدخلات والخوارزمية والقيود والتقييم، التداخل معنا، فرق تقني قابل للاختبار. نختار ثلاثة أعمال قريبة على الأقل؛ إذا وجد نفس الدمج نقنن فرقنا ولا ندعي أصالة مطلقة. تلحق مصفوفة المقارنة عند التحقق، لا نملؤها باستنتاجات من محادثة فقط.
