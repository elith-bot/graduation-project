# شرح فكرة المشروع ونطاقه

## الاسم والمشكلة

Automated SOC Analyst Assistant & Incident Triage Engine — مساعد محلل مركز العمليات الأمنية ومحرك الفرز الأولي للحوادث.

تستقبل مراكز العمليات الأمنية SOC تنبيهات كثيرة: بعضها مكرر، وبعضها يشير لنشاط سليم، وبعضها يحتاج تحقيقاً عاجلاً. هدفنا تقليل عبء المراجعة بواسطة تجميع الأدلة وتحليل السياق وترتيب الأولويات، مع قياس الهجمات التي قد يفوتها النظام. لا نفترض نسبة ثابتة للتنبيهات الخاطئة قبل جمع البيانات ووسمها.

## مثال يوضح الفكرة

خمس عشرة محاولة دخول فاشلة ثم نجاح يمكن أن تنتج عن مستخدم نسي كلمة المرور أو مهاجم خمنها. هذا التسلسل وحده لا يثبت أياً منهما. نفحص تاريخ المصدر والجهاز، ونتائج MFA إن توفرت، وعدد الحسابات المستهدفة، والنشاط اللاحق الذي وصل فعلاً وقت القرار.

يمكن جمع التنبيهات الستة عشر في حادث واحد مع خط زمني وأسباب الأولوية. إذا غاب السياق تبقى الحالة تحتاج مراجعة، ولا تصنف سليمة تلقائياً. الجهاز أو المصدر المعروف ليس ضماناً؛ قد يكون مخترقاً.

## المصطلحات

| المصطلح | المعنى داخل المشروع |
|---|---|
| Event | واقعة مسجلة في النظام |
| Alert | تنبيه أمني ناتج عن قاعدة أو أداة كشف |
| Incident | حالة تجمع أحداثاً مترابطة للتحقيق، ولا تعني وحدها اختراقاً مؤكداً |
| Duplicate | إعادة إرسال أو تنبيه مكرر؛ لا يساوي نشاطاً سليماً |
| False Positive | نشاط سليم صنف كتهديد وفق الحقيقة المرجعية وتعريف الاختبار |
| Low Priority | أولوية مراجعة منخفضة، وليست حكماً نهائياً بالسلامة |
| Needs Review | نتيجة التحقيق غير محسومة بسبب الأدلة المتاحة |

الأولوية High/Medium/Low منفصلة عن حالة التحقيق وعن الحكم benign/malicious/unknown. الدرجة القاعدية لترتيب المخاطر وليست احتمالاً رياضياً بأن الشخص مهاجم.

## ما نبنيه وما نستفيد منه

يوفر [Wazuh](WAZUH.md) الجمع والتحليل والتنبيهات، ولديه أصلاً قواعد وقدرات ربط. نبني فوق مخرجاته محرك تجميع وربط سياقي وأولوية مفسرة وواجهة تحقيق وتقييم مقارن؛ لا ندعي أن كل ربط أحداث ابتكار جديد.

| المرحلة | المخرج ومعيار الانتقال |
|---|---|
| MVP 1: قواعد | مدخلات اصطناعية بعقود محددة، تجميع وربط وخمس قواعد وأسباب قرار واختبارات قابلة للتكرار |
| MVP 2: تكامل | موصل Wazuh حقيقي موثق، وسياق متاح فعلاً، وعرض الأدلة والتقرير وقرارات المحلل |
| النسخة البحثية: Hybrid | نموذج مدرب بوسوم مستقلة، يعمل أولاً في Shadow Mode، ومقارنة تثبت فائدته قبل تأثيره على الأولويات |

Hybrid هنا يجمع قواعد أمنية وتعلماً آلياً؛ التلخيص بنموذج لغوي وظيفة أخرى اختيارية، ولا يحل محل التصنيف أو الأدلة. لا ننفذ احتواءً تلقائياً أو حظراً في النسخة الأولى. كل الأحداث الأصلية تبقى قابلة للتتبع وفق سياسة احتفاظ تحدد عند التنفيذ؛ إزالة التكرار تخص قائمة العمل ولا تمحو الأدلة.

## تجربة المحلل المطلوبة

عرض قائمة الحوادث وأولوياتها، البحث والتصفية، فتح الخط الزمني والتنبيهات الأصلية، قراءة أسباب القرار والحقول المفقودة، تسجيل ملاحظة وحكم المحلل، ثم استخراج تقرير. أي حكم يذكر صاحبه ووقته؛ ملاحظات المحلل لا تعيد تدريب النموذج تلقائياً دون مراجعة جودة الوسوم.

## حدود النسخة البحثية

نبدأ بأحداث المصادقة والنشاط الحساس بعد الدخول في مختبر مصرح به. إنشاء المستخدم ورفع الصلاحيات وتعديل ملف حساس أمثلة للنشاط اللاحق؛ تعميم الكشف لكل أنواع الهجمات خارج النطاق الأول. لا نعد بكشف قطعي أو نتائج على بيئات حقيقية اعتماداً على بيانات اصطناعية وحدها.

## حالة المستودع

هذه مواصفات تصميم، وليست ميزات منفذة. لا يوجد تأكيد بأن مختبر Wazuh جاهز أو أن البيانات موسومة أو أن ML مدرب. الفريق خمسة مبدئياً وقابل للتغيير؛ الأسماء لم تسند لأدوار تقنية بعد.
