# صمود الكشف: وحدة SHIELD-X

وحدة تصميم مقترحة داخل المنصة، لا مشروع منفصل ولا ادعاء كشف كل الأعطال. هدفها قياس أثر فقد مكونات المراقبة على سلوك محدد، واقتراح تحسين والتحقق منه. لا تحل محل Wazuh ولا تفترض أن مراقبة حالة Agent وحدها تكفي.

## ما نبنيه أولاً

كتالوج صغير مكتوب يدوياً: سيناريو رصد عملية اختبارية محددة على جهاز مختبري، ومساران مثل Windows Security 4688 وSysmon Event 1 إذا وفرا فعلاً الحقول المطلوبة. يجب تهيئة التسجيل وشروط القاعدة واختبار السلوك نفسه على كل مسار؛ Event 4688 وSysmon Event 1 ليسا متكافئين تلقائياً ولا مستقلين لمجرد اختلاف اسميهما.

السيناريو يدعم التحقيق بعد الدخول ولا يثبت شرعية الحساب أو تغطية كل أوامر PowerShell. لا نربط كل قاعدة بكل تقنية MITRE أو نسميها تغطية كاملة.

## النموذج

- Asset: الجهاز وأهميته ونطاق المختبر.
- Component: مصدر أحداث، جامع، Agent، نقل، Decoder، قاعدة، Server، Indexer أو نقطة عرض، بمعرف ثابت.
- DetectionScenario: السلوك وشروط النجاح والفترة والحقول الضرورية.
- DetectionPath: شروط نجاح مسار واحد وتبعياته والأدلة التي تثبت اختباره.
- Dependency: اعتماد مطلوب أو بديل؛ النموذج الأول قائمة مسارات، كل مكون داخل المسار مطلوب (AND) والطرق بدائل (OR).
- TestRun: المدخل المتوقع والفعلي، الأوقات، نقطة المراقبة، نسخة الإعداد، النتيجة والأدلة.

حدد نقطة النجاح: توليد الحدث، جمعه، تحليله وإنتاج التنبيه، أو وصوله للبحث. فشل الفهرسة لا يعني بالضرورة فشل إنتاج التنبيه؛ تعرض نقطتا النجاح منفصلتين. يسجل كل مسار إطار الصلاحية والإصدار، وأي مكون لم نتحقق منه.

## حساب الفشل المحدود

للسيناريو s مجموعة مسارات مختبرة P، ولكل مسار p مجموعة مكونات D(p)، وللمحاكاة مجموعة أعطال F:

`available(s, F) = يوجد مسار p في P بحيث D(p) ∩ F فارغة`

نبحث عن أقل عدد مكونات يكفي لفقدان جميع المسارات المختبرة. هذا مكافئ لضرب كل مسار بمكون فاشل، وليس حساب استقلال احتمالي. نفرق بين minimum (الأصغر عدداً) وminimal (لا يمكن حذف عنصر منها مع بقاء الفشل). نعرض المجموعات والحدود لا رقماً بلا تفسير.

مثال: A={channel_a, agent, server} وB={channel_b, agent, server}. المجموعة {agent} وحدها توقف الاثنين. فصل قناتين لا يعالج اعتماد server المشترك. إذا استبعدنا server من نموذج أعطال التجربة يجب التصريح بذلك، لا إعلان صمود شامل.

ابدأ ببحث شامل لكل المجموعات على كتالوج صغير وبحد أقصى k موثق؛ إذا لم نجد مجموعة ضمن k نسجل «لم توجد ضمن الحد المختبر»، ولا نقول لا توجد. إذا لا توجد مسارات verified فالنتيجة unknown/لا قدرة مثبتة وليست margin=0 موحياً بأننا أثبتنا كل شيء. الخريطة غير المكتملة لا تبرر تأكيد أن كل السيناريوهات فشلت أو نجت.

هذه مفاهيم تحليل تبعيات ومجموعات فشل معروفة. اسم MDFS داخل المحادثات تسمية عمل، وليس برهان أصالة رياضية. المساهمة المحتملة في ربطها بنتائج تحقق وتجربة تحسين؛ انظر [خطة البحث](RESEARCH.md).

## الفشل والتوصيات

| الطبقة | مثال فشل | كيف نتحقق؟ |
|---|---|---|
| المصدر | الحدث لا يتولد | توليد نشاط اختبار معروف وملاحظة المصدر |
| الجمع | قناة غير مهيأة رغم اتصال Agent | مقارنة المصدر بما يصل للجامع |
| النقل | عدم وصول السجل | دليل إرسال واستقبال ومهلة واضحة |
| التحليل | الحقول لا تفك أو القاعدة لا تطابق | سجل ثابت وLogtest ثم اختبار المسار الكامل |
| الفهرسة/العرض | تنبيه موجود غير قابل للبحث | فحص إنتاج التنبيه وفهرسته منفصلين |
| مشترك | Agent أو Server تعتمد عليه مسارات كثيرة | خريطة ثم تعطيل مصرح به وإعادة الاختبار |

غياب الأحداث ليس اختبار صحة وحده؛ ربما لا يوجد نشاط. Silent telemetry failure المتقدم يحتاج heartbeat/نشاطاً معروفاً أو قياساً مستقلاً، ويؤجل بعد MVP.

الإصلاح يعيد وظيفة متوقعة (تهيئة قناة متوقفة)، أما زيادة الصمود فتثبت استمرار السلوك المطلوب تحت الفشل المحدد. توصية بقناة ثانية على Agent نفسه قد تعالج فشل القناة ولا تعالج فشل Agent. نختار تحسيناً محدوداً متاحاً للمختبر، ونذكر أي اعتماد مشترك باقٍ.

## تجربة القبول

1. إثبات السلوك والمسارين دون عطل؛ ربط كل نتيجة بدليل ونسخة إعداد.
2. محاكاة فقد قناة على الخريطة وتوقع المسار المتبقي؛ اختبار الفقد في المختبر ومقارنة التوقع.
3. تكرار ذلك للمكوّن المشترك؛ لا يثبت Logtest وحده انتقال الحدث كاملاً.
4. تنفيذ تحسين واحد بعد موافقة مسؤول المختبر مع خطة رجوع، ثم إعادة اختبار السلوك والفشل نفسيهما.
5. إعلان ما تحسن وما لم يتحسن وما بقي unknown. إذا لم يتوفر مسار مستقل فعلي، نعرض تحسيناً محدوداً ولا ندعي إثبات تحمل فشل Agent.

كل تعطيل محصور بالمختبر، موثق قبل وبعد مع استعادة الإعداد. لا توفر النسخة الأولى زر API يعطل أجهزة أو يغير إعداداتها تلقائياً.
