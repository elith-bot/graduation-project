# ADR 0001: منصة موحدة بنطاق أول محدود

الحالة: قرار تصميم للنسخة الأولى بناء على اتفاق الفريق في المحادثة، ينتظر مراجعة طلب الدمج. لا يغير إعدادات GitHub.

## الاختيار

تطبيق FastAPI واحد يخدم HTML/CSS/JavaScript ويتبادل JSON عبر /api/. engine مكتبة Python منفصلة عن التخزين تضم الفرز والتحقيق والصمود. موصل Wazuh داخل integrations. SQLite اختيار أول للتخزين المحلي الصغير، مع ترحيلات وحدود تزامن ونسخ احتياطي موثقة عند التنفيذ. NetworkX خيار مساعد عند تنفيذ الرسم وليس اعتماداً مثبتاً أو شرطاً للحساب الأول الصغير.

نثبت إصدار Python المتاح والمدعوم لدى أعضاء الفريق ومدير الاعتماديات في مهمة التجهيز؛ لا نعلن إصدارات غير مجربة. لا توجد خدمة ML/LLM أو مفتاح مدفوع مطلوب لـMVP.

## السبب

خمس مسؤوليات وفترة هدفها 6 أسابيع وأسبوعان احتياط. فصل تطبيقين كاملين أو اعتماد خدمات موزعة يزيد الربط والتشغيل. الدمج بالمكتبات والعقود المشتركة يسمح بمسار صغير كامل أولاً دون تغيير أدوات الواجهة التي يعرفها الفريق.

## التنازلات

SQLite ليس قراراً لنشر متعدد الخوادم أو حمل كتابة كبير. إذا ظهر احتياج تزامن أو حجم يتجاوزه يثبت بالقياس ثم يدرس PostgreSQL بقرار مستقل. لا نعد أن النطاق المتقدم لـSHIELD-X وML ينجز خلال الشهرين. الأولوية لإثبات التسلسل والتجربة المحدودة.

لا نغير اسم المستودع أو حساباته. الاسم الأصلي SOC Analyst Assistant محفوظ تاريخياً؛ العنوان الموحد الجديد وصفي ويثبت رسمياً مع المشرف.
